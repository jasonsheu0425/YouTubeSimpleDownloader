# v0.9.8 Post-Release Verification Report

## 1. Release Summary

YouTube Simple Downloader v0.9.8 is the Security Hardening release. It
strengthens YouTube and thumbnail URL validation, bounds thumbnail retrieval,
removes the arbitrary `PATH` ffprobe fallback, uses the verified FFmpeg
fallback for media probing, adds probe timeouts, and contains custom filename
templates under the selected output folder.

The release did not change the history schema or add unrelated feature scope.

## 9. Scope Summary

The release covers:

- strict supported HTTPS YouTube URL validation
- thumbnail host, redirect, content-type, timeout, and 5 MiB size controls
- graceful metadata preview when thumbnail retrieval fails
- removal of arbitrary `PATH` ffprobe execution
- verified FFmpeg media-probe fallback with a 15-second timeout
- custom filename template containment
- rejection of traversal, absolute, drive-relative, UNC, and POSIX absolute
  output templates

It does not claim to eliminate all security risk.

## 10. Known Non-blocking Notes
