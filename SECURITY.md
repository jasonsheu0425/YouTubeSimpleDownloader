# Security Policy

## Supported versions

The latest release on the `main` branch is supported for security fixes.

## Reporting a vulnerability

Please do not publish security-sensitive details in a public GitHub issue. Contact the repository owner privately through the GitHub profile first, with a minimal description and safe reproduction steps.

Do not include cookies, tokens, login information, private URLs, downloaded private media, or other personal data in any report.

This application does not support login or cookies and is intentionally limited to public or unlisted content that does not require authentication.

## Local history and privacy

The local history file may contain YouTube URLs, video titles, full local output paths, and local source paths used for transcoding. On Windows it is stored under:

```text
%LOCALAPPDATA%\YouTubeSimpleDownloader\history.json
```

Treat this file as private. Review and redact it before attaching it to a support request, security report, public issue, or diagnostic archive. A report normally does not need the complete history file; provide only the smallest sanitized record needed to reproduce the problem.
